IMPORTANT INFO.

BPM: 170
FILE TYPE: .ogg

Use the "Voices" file as an easier way to chart the song but I would personally recommend you to use the "IN-GAME" file for a playable public version.

Why? you might ask, it's because this way you can prevent the playable version to have any sort of volume problems! If the instrumental and the voices are in separated files it creates all sorts of issues, such as unpleasant saturation and compression.
But at the end of the day it's your call, the files are there for you to do whatever you want with them (for charting).
